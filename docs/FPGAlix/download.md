# Downloads

Quartus Prime 22.1, the ARM GNU toolchain
(`arm-gnu-toolchain-12.3.rel1-x86_64-arm-none-linux-gnueabihf`), and the
Ubuntu 22.04 LTS image, used to install the development environment on
the host PC ([00. Prepare Your Dev Environment](00_PrepareDevEnvironment.md)),
are all available from their respective official sites. A copy of all
three, for convenience, is also mirrored here:

[UniTS SharePoint folder](https://units-my.sharepoint.com/:f:/g/personal/s133932_ds_units_it/IgCUoXfERelfT7MK33S5s3mCAS_ia6fI6KJ4DiAp4tTX6Gw?e=oKP6TL)
(a UniTS account is required; the folder cannot be made public).

The same folder also holds a prebuilt SD card image for the DE1-SoC
board itself, bootloader, kernel, root filesystem and FPGA bitstream
already built, letting the board boot without going through the full
build process (see [README.md, Quick Start](README.md#quick-start)).
